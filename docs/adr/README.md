# Architecture decision records

One record per significant decision, in the order they were made, each saying
what was decided, what forced the choice and what it costs. A record is never
edited to change its mind: a decision that changes gets a new record that
supersedes the old one, and the old one's status says so. The current shape of
the system is in [ARCHITECTURE.md](../../ARCHITECTURE.md); this is the "why".

A decision belongs here when it would cost real rework to reverse, or when the
obvious alternative was tried and rejected for a reason worth remembering. A
naming choice or a linter setting doesn't, and a change's own working paper
under `openspec/changes/` is archived once it ships, so a decision that should
outlive it gets a record here.
