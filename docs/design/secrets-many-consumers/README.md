# Secrets table with many consumers

Screens from the Stitch project "Automated Code Audit Tool"
(2077449843142415547), generated for the secrets table when a variant has
up to a hundred consumers. The table names two consumers per row and counts
the rest; the full list opens in a dialog with a filter box.

| File                               | Shows                                                       |
| ---------------------------------- | ----------------------------------------------------------- |
| `screen-secrets-table.png`         | Desktop Secrets Overview                                    |
| `screen-secrets-table-rows.png`    | The rows: two consumers and a `+10 more` button             |
| `screen-consumers-dialog.png`      | Secrets Overview and consumers dialog                       |
| `screen-consumers-dialog-crop.png` | The dialog: count, filter, `3 of 100 shown`, scrolling list |

Only the row and dialog behaviour is built from these. The rest of the
Stitch styling (navigation, footer strip, icon actions) is a separate redesign.
